Auto-sync interval

Version history

A short rollback history, not a full audit log — keeps roughly your last 40 saves so you can undo a mistake, works fully offline, and shows what actually changed in each one. Restoring saves that version as your new current one; nothing already in your history is ever deleted. When GitHub sync is connected, older saves beyond that local window fill in from its commit log too.

Journal data (Timeline, Categories, Backlog)

Export or import just your timeline entries and backlog, as JSON or CSV.

Finance data

Export or import your finance entries, categories, and recurring expenses, as JSON or CSV.

Finance CSV import expects the yearly pivot format exported from a Google Sheets export (year blocks, 12 month columns, a note on each real transaction); big one-off purchases with no month become "yearly expenses." Every import goes through the same review screen as Journal data.

API keys

Source per category

Choose which API to use for each of your categories, plus an optional fallback that's only tried when the primary source finds no matches. Categories set to "None" won't fetch metadata. These assignments sync across your devices. Categories set to "Steam" show a manual Steam App ID field instead of search (Steam has no browser-callable search API) — paste the ID from the game's store URL to get cover art and, once a GG.deals key is set above, current lowest prices. "RAWG + Steam + GG.deals" searches RAWG as normal, but also looks up a Steam App ID via RAWG's own store links for whichever result you pick — when found, that entry gets cover, rating, length, and current price all at once, no manual App ID needed; when the game isn't on Steam, it falls back to a plain RAWG entry.

Steam Wishlist import

Pulls your whole Steam wishlist in one request and lets you review it before anything's added — nothing is added automatically, and re-syncing later won't re-add titles already in your backlog. Your Steam wishlist must be set to Public (Steam → Privacy Settings → Game details) or this comes back empty. Requires a small proxy of your own in front of Steam's endpoint — see proxy/README.md for the one-time setup.
