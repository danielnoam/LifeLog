Settings

Active storage

Local file (this device)

Stores your data in a .json file you choose on this computer. Good for keeping a local backup or syncing via a folder shared with Google Drive / Dropbox. Works on desktop Chrome and Edge only — not supported on phones.

GitHub sync (works on all devices)

  1. Create a GitHub token →, click Generate token, and copy it.
  2. Paste it below and press Connect — a private data repo is created for you automatically.
Advanced

Keeps your phone and desktop in sync via a private GitHub repo. Every save becomes a commit, giving you a full version history. Your token stays in this browser only — it is never sent anywhere else.

Add another device

Scan the QR code with your phone camera (or open the link) to connect a new device instantly — no manual setup needed.

You're on a local/localhost URL, so this link only works on this computer. Open your published site (e.g. GitHub Pages) and copy the link from there to use it on other devices.

The setup link is too long for a QR code — use the copy button below to share it instead.

This link contains your access token — only share it with your own devices.

Auto-sync interval

When enabled, LifeLog periodically pulls changes saved from your other devices. This setting is per-device.

Export & import

Download a full copy of your data or restore from a previous backup.

JSON keeps everything (entries, categories, backlog, achievements). CSV exports entries only and is useful for spreadsheets. Importing JSON merges with your current data — it does not replace it.

App lock (this device only)

Require a PIN or your device's fingerprint/Face ID to open LifeLog. This is a lock on this device only — it isn't synced to your other devices, and it doesn't encrypt your data. If you forget your PIN, the lock screen's reset option wipes this device's local copy of the data (so it isn't a free bypass) — if GitHub or a local file is connected you can reconnect afterward to get your data back; if not, the wipe is permanent.

After unlocking, refreshing or reopening the app within this window won't prompt again. Once the window passes, the next open asks again.

Unlock method

Fingerprint/Face ID isn't available on this device or browser.

Timeline layout

Controls how wide each month card is in the Timeline view.
• Min width — smaller values fit more months per row.
• Max width — set to 0 to let cards stretch and fill the available space.

Font

Changes the typeface used throughout the app on this device only.

Media enrichment

Fetches cover art and metadata while you type a title. This switch is per-device — the API keys and per-category sources you set up in the Media tab sync everywhere, but each device decides independently whether to use them.

API keys

Synced across your devices like the rest of your data — paste a key once and it's available everywhere.

Open Library, AniList, Google Books, and MusicBrainz all work without a key.

Source per category

Choose which API to use for each of your categories. Categories set to "None" won't fetch metadata. These assignments sync across your devices. Games synced via "Steam" also show current lowest prices on backlog cards once a GG.deals key is set above.

Media enrichment is off on this device — turn it on in Settings → Appearance.

Pick which version to keep

Your data differs between where it's saved. Choose the version to keep — it'll be copied to the others.
