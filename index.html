Media sources

CORS proxy

A small proxy of your own that the metadata sources which don't send CORS headers get routed through, since a browser can't call them directly. Right now that's SteamGridDB cover art, GG.deals prices, and the Steam Wishlist import further down — all three share this one URL. One-time setup: see proxy/README.md. Leave it blank if you don't use any of those; RAWG, TMDB, Open Library, AniList, Jikan, Google Books, and MusicBrainz all work without it. Any source added later that's CORS-blocked will route through here too.

API keys

Synced across your devices like the rest of your data — paste a key once and it's available everywhere.

Open Library, AniList, Jikan, Google Books, and MusicBrainz all work without a key.

Source per category

Choose which API to use for each of your categories, plus an optional fallback. Bulk sync and the background checks only try the fallback when the primary finds no matches; the manual "🔄 Sync" button searches both at once and lists the matches together, each tagged with the source it came from, so you can pick from either — whichever source answers first appears first, and the other's fill in underneath when they arrive. Categories set to "None" won't fetch metadata. These assignments sync across your devices. Categories set to "Steam" show a manual Steam App ID field instead of search (Steam has no browser-callable search API) — paste the ID from the game's store URL to get cover art and, once a GG.deals key is set above, current lowest prices. "RAWG + Steam + GG.deals" searches RAWG as normal, but also looks up a Steam App ID via RAWG's own store links for whichever result you pick — when found, that entry gets cover, rating, length, and current price all at once, no manual App ID needed; when the game isn't on Steam, it falls back to a plain RAWG entry.

Upcoming releases

Backlog items that haven't come out yet are the only thing here that goes out of date on its own — a "TBA" gets a date, a date slips, a season starts airing. This re-asks each waiting item's own source using the media ID already stored on it, and updates just its release date. It never renames, re-covers, adds, or removes anything. Only items still waiting are checked, so it's a handful of requests even on a large backlog. Steam, RAWG, TMDB, and AniList items can be re-checked; Open Library, Google Books, MusicBrainz, and Jikan items are skipped (no reliable lookup by ID, and books and albums rarely sit in a backlog unreleased).

Runs quietly when you open the app, at most this often, so the Next Releases list is current without you asking. It only ever changes release dates on items you already have.

Steam Wishlist import

Goes through the CORS proxy set above (Steam's endpoint isn't browser-callable), so set that first if you haven't.
